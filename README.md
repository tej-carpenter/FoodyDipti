# Food Influencer Recipe Web App

Next.js App Router application for a single food influencer to upload recipes and for users to browse and save favorites.

## Stack

- Next.js
- Tailwind CSS
- Firebase Auth, Firestore, Storage
- Vercel deployment

## Setup

1. Copy `.env.example` to `.env.local` and fill in Firebase values.
2. Install dependencies.
3. Run `npm run dev`.

## Firebase collections

- `users`
- `recipes`
- `favorites`
